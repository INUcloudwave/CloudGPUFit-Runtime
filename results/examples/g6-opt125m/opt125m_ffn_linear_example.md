# OPT-125M 단일 연산 실행시간 예측 예시

- 인스턴스: `g6.xlarge`
- 입력: Batch 8, 입력 길이 512, 출력 길이 128, FP16
- 선택 연산: 첫 번째 Transformer block의 FFN 확장 Linear
- 입력 Tensor: `[4096, 768]`
- 가중치 Tensor: `[3072, 768]`
- 출력 Tensor: `[4096, 3072]`

## 계산

- M = 4,096, N = 3,072, K = 768
- 연산량 = 2 × M × N × K = **19.33 GFLOPs**
- 메모리 접근량 = (M × K + K × N + M × N) × 2 bytes = **36.18 MB**
- 연산 기준 시간 = 0.154249 ms
- 메모리 기준 시간 = 0.120567 ms
- Roofline 시간 = max(연산 기준, 메모리 기준) = **0.154249 ms**
- LightGBM 보정 배율 = **2.5459배**
- 최종 연산 실행시간 예측 = **0.392703 ms**

메모리 접근량의 발표용 공식에서는 bias를 생략하였다. 실제 예측 피처에는 bias 접근량도 포함되지만 반올림한 36.18 MB에는 영향을 주지 않는다.
